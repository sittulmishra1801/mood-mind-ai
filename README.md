# MoodMind AI 🧠✨

MoodMind AI is an AI-powered mood journaling application that helps users understand their emotions through intelligent mood analysis and personalized wellness suggestions.

## 🚀 Features

* AI-powered mood detection
* Personalized emotional insights
* Wellness recommendations
* Journal history tracking
* Dark mode support
* Responsive design
* Clean and modern UI
* Local storage support

---

## 🛠️ Tech Stack

### Frontend

* React.js
* Vite
* CSS3

### Backend

* FastAPI
* Python

### AI

* Google Gemini API

### Storage

* LocalStorage

## ⚙️ Installation

### Frontend

```bash

```

### Backend

```bash
pip install -r requirements.txt
uvicorn main:app --reload
```
